Privacy Policy

This policy covers the Slopoverse website and Slopoverse Publisher, the tool we use to post our own videos to our own accounts on TikTok, YouTube, Instagram, Threads and Bluesky.

Who uses the tool

Only the Slopoverse team, for the Slopoverse accounts. The tool has no public sign-up and no other users.

What we collect

From the platforms we connect, the tool receives only what's needed to post to our own accounts: the account's basic profile (such as its ID and username) and the access tokens the platform issues. It doesn't collect data about viewers, followers or any other people.

How it's used and stored

Tokens and post results (post IDs and links) are stored on our own computer and used only to publish and track our own posts. We don't sell, share or transfer this data, and don't use it for advertising.

This website

The site is static and hosted by GitHub Pages. We don't set cookies or run analytics. GitHub may keep standard server logs; see GitHub's privacy statement.

Deletion

We can disconnect any platform at any time, which deletes its tokens from our computer. You can also revoke the tool's access from the platform's own settings.

open an issue on this site's GitHub page.
